# 买币记录功能说明

## 功能概述
新增的买币记录功能允许用户查看和删除他们的加密货币购买历史记录，包括买入价格、买入数量、买入时间等信息。这是一个简单的记录查看系统，提供基本的查询和删除功能，不区分用户状态。

## 数据库表结构

### buy_records 表
| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | uint | 主键ID | 自增，唯一 |
| created_at | time.Time | 创建时间 | 自动生成 |
| updated_at | time.Time | 更新时间 | 自动更新 |
| deleted_at | time.Time | 删除时间 | 软删除 |
| currency | string(20) | 币种标识 | 必填，如BTC、ETH、USDT |
| buy_price | decimal(20,8) | 买入价格 | 必填，支持8位小数 |
| buy_amount | decimal(20,8) | 买入数量 | 必填，支持8位小数 |
| buy_time | time.Time | 买入时间 | 必填 |

## API接口

### 1. 获取买币记录列表
- **接口**: `GET /api/buyRecords`
- **认证**: 无需认证
- **查询参数**:
  - `currency`: 币种筛选（可选）
- **说明**: 一次性返回所有记录，按创建时间倒序排列

### 2. 删除买币记录
- **接口**: `DELETE /api/buyRecords/{id}`
- **认证**: 无需认证
- **说明**: 软删除，不会真正删除数据





## 使用示例

### 查询记录列表
```bash
# 查询所有记录
curl -X GET "http://localhost:3000/api/buyRecords"

# 按币种筛选
curl -X GET "http://localhost:3000/api/buyRecords?currency=BTC"
```

### 删除记录
```bash
curl -X DELETE "http://localhost:3000/api/buyRecords/1"
```

## 注意事项

1. **权限控制**: 所有接口都无需认证，任何人都可以操作记录
2. **数据验证**: 买入价格和数量必须为正数
3. **时间格式**: 买入时间支持RFC3339格式，如果不提供则使用当前时间
4. **软删除**: 删除操作采用软删除，数据不会真正丢失
5. **数据隔离**: 这是一个简单的记录系统，所有记录共享，不区分用户

## 数据库索引

为了提高查询性能，建议在以下字段上创建索引：
- `user_id` - 用户ID索引
- `currency` - 币种索引
- `status` - 状态索引
- `buy_time` - 买入时间索引
- `created_at` - 创建时间索引
